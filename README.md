One line. One auto-reply. The funniest thing a coworker reads all week.

> I'm out of office until Monday. Your email is very important to me, which is why I've ignored it with such dedication.

## Run it

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./out/entry.txt` by default).
